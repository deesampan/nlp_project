# Website

Plain HTML, CSS and JavaScript. No build step, no framework.

## Run it

Double-click `start.bat` in the project root, or:

```bash
cd src
../.venv/Scripts/python app.py
```

Then open <http://localhost:8000>.

`app.py` serves this folder with browser caching turned off. Use it rather than
`python -m http.server`, which lets the browser reuse an old `data.js` and show the
*previous* run's numbers after a rebuild, silently and with no error.

If you ever do see stale numbers, hard-refresh with `Ctrl` + `F5`.

## Files

| File              | Purpose                                                        |
| ----------------- | -------------------------------------------------------------- |
| `index.html`      | Home page — one card per restaurant                            |
| `restaurant.html` | One restaurant — menu ranked by how many people liked each dish |
| `app.js`          | Renders both pages from `data.js` and `removed.js`             |
| `styles.css`      | All styling                                                    |
| `data.js`         | Generated by `run_pipeline.py` — do not edit by hand           |
| `removed.js`      | Reviews the cleaning step left out, with the reason — generated |
| `img/`            | Dish photos, generated from `src/image/`                       |

## Regenerating the data

From the project root:

```bash
.venv/Scripts/python run_pipeline.py
```

Rewrites `data.js` and `removed.js`. Refresh the browser to see changes.
